# Kaleido visual identity

Kaleido is styled as an independent city-culture journal rather than a generic event SaaS dashboard.

## Art direction
- **Concept:** A printed field guide to the interesting things happening around a city.
- **Palette:** warm paper `#F3EADF`, ink plum `#28212D`, vermilion `#EF6546`, butter yellow `#E8C95B`, and muted mauve-grey `#766B72`.
- **Typography:** Fraunces for expressive editorial headlines, Manrope for interface and body copy, and DM Mono for metadata and labels.
- **Composition:** asymmetric image framing, fine ink rules, compact uppercase metadata, oversized serif display type, and restrained paper-grain texture.
- **Dark mode:** ink-plum surfaces with warm paper text and a brighter vermilion accent.

The existing React routes, event data, search and category filters, event detail pages, registration flow, local-storage preferences, and responsive breakpoints are retained.
